# 공식 사건 압력 (PEP / NEP) — V3 방법론

**결과를 보기 전에 규칙을 고정했습니다.** 아래 정의는 V3 예측을 한 번도 실행하기 전에
문서와 설정 파일로 커밋됐고, 실행 후에는 수정하지 않았습니다.

---

## 1. 무엇을 재는 신호인가

- **PEP (상승 압력)** — 철·강 스크랩 가격을 **올리는 방향**으로 작동하는, 공식 문서로
  확인 가능한 압력의 강도
- **NEP (하락 압력)** — 같은 기준의 **내리는 방향** 압력

세 가지를 분명히 합니다.

1. **감성분석이 아닙니다.** "뉴스 논조가 좋다/나쁘다"가 아니라 "가격 형성 경로에 어떤
   방향의 압력이 걸려 있는가"입니다.
2. **PEP + NEP ≠ 1.** 둘은 독립입니다. 관세는 국내 강재가를 올리는 동시에 수입·전방
   수요를 누릅니다 — 두 값이 함께 올라갑니다.
3. **누적 총량이 아니라 압력입니다.** 8년째 유지 중인 관세는 이미 가격에 반영된
   **baseline** 이지 새로 가해지는 압력이 아닙니다.

---

## 2. 왜 V3 를 만들었나

V2 에서 M1(시장 데이터)과 M2(+사건 압력)의 예측선이 거의 겹쳐 보였습니다. 원인을
추측하지 않고 측정했습니다.

| 측정 항목 | 값 |
|---|---|
| 사실상 0 인 계수 | **0 / 100** |
| 예측 시점 50개에서 PEP 의 서로 다른 값 | **4** |
| 예측 시점 50개에서 NEP 의 서로 다른 값 | **3** |

계수가 0 인 경우가 하나도 없었습니다 — 모델은 사건 정보를 버리지 않았습니다. 그런데
PEP 는 서로 다른 값이 4개뿐이었습니다. **모델이 신호를 무시한 것이 아니라 줄 신호가
없었습니다.**

---

## 3. 사건을 어떻게 기록하나 — 사안(episode) + 상태 변화(transition)

V2 는 사건을 평평한 목록으로 담았습니다. 그래서 "Section 232 철강"처럼 8년에 걸쳐
성격이 여러 번 바뀐 사안이 서로 무관한 기록 여러 개로 흩어졌습니다.

```
사안(episode)          지속되는 사안 하나          (Section 232 철강, COVID-19, ...)
                       속성: 분류, 직접성, 범위, 경제적 경로, 시작/종료
  └ 상태 변화(transition)  그 사안의 공식 상태 변화 하나
                       속성: 단계, 알려진 날짜, 상승/하락 방향, 공식 출처
```

| | V2 | **V3** |
|---|---|---|
| 기록 | 사건 17 | **사안 17 + 상태 변화 49** |
| 분류 수 | 6 | **7** |
| 단계 어휘 | 5종 | **8종** |
| 최초 기록 | 2016-07 | **2015-06** |

## 4. 점수 축

각 **사안**이 두 축, 각 **상태 변화**가 단계를 통해 세 번째 축을 받습니다.

**직접성 (0–3)** — 스크랩 수급·원가에 얼마나 직접 작용하는가
| 점수 | 기준 |
|---|---|
| 0 | 인과 경로가 확인되지 않음 → **기록하지 않음** |
| 1 | 거시·심리 경로를 거쳐 간접 작용 |
| 2 | 철강 산업 또는 에너지·물류 원가에 직접 작용 |
| 3 | 철·강 제품 교역 또는 스크랩 자체의 수급에 직접 작용 |

**범위 (0–3)** — 영향 범위
| 점수 | 기준 |
|---|---|
| 0 | 단일 기업·단일 항만 수준 → **기록하지 않음** |
| 1 | 단일 품목 또는 소수 상대국 |
| 2 | 복수 품목·복수 상대국 또는 미국 전역 산업 |
| 3 | 전 세계 교역·에너지·물류 구조에 걸침 |

**확실성 (0–1)** — 단계로부터 **자동 결정**됩니다 (임의 입력이 아닙니다)

| 단계 | 확실성 | 반감기(월) | 잔존 하한 | 최대 활성(월) | 의미 |
|---|---|---|---|---|---|
| SIGNALLED | 0.20 | 2 | 0.00 | 6 | 의향·위협·검토. 아직 조치가 아님 |
| PROPOSED | 0.35 | 3 | 0.00 | 9 | 구체안 공식 제안, 의견수렴 중 |
| ANNOUNCED | 0.60 | 3 | 0.10 | 12 | 발효일과 함께 발표, 시행 전 |
| CONFIRMED | 0.75 | 4 | 0.10 | 12 | 기존 상태의 지속·연장 확인 |
| IMPLEMENTED | 1.00 | 6 | 0.15 | 무기한 | 실제 발효되어 작동 중 |
| ESCALATED | 1.00 | 4 | 0.20 | 무기한 | 발효 중 상태가 확대 |
| DE_ESCALATED | 0.60 | 4 | 0.05 | 12 | 발효 중 상태가 축소·완화 |
| ENDED | 0.30 | 3 | 0.00 | 9 | 공식 종료. 종료 자체가 방향을 가짐 |

```
기본강도 = ( 직접성/3 + 범위/3 + 확실성 ) / 3        ∈ [0, 1]
```

## 5. 시간 구조

```
가중치(a) = 잔존하한 + (1 − 잔존하한) × 0.5 ^ (a / 반감기)
a = 알려진 뒤 지난 개월 수
```

V2 의 결정적 결함은 IMPLEMENTED 가 한 번 켜지면 몇 년간 값이 상수였다는 점입니다.
V3 는 **충격이 새것일수록 세고 지속 상태는 낮은 잔존 수준으로 가라앉게** 만듭니다.

---

## 6. 집계

```
상승_t        = 기본강도 × 가중치 × 상승방향
사안값        = 그 사안의 활성 상태 변화 중 최댓값        ← 중복 통제
분류값        = 그 분류의 사안값 중 최댓값                ← 같은 채널 = 독립 증거 아님
PEP           = 1 − Π(1 − 분류값)                        ← 다른 채널 = 독립 증거
```

정의상 `0 ≤ PEP, NEP ≤ 1`.

- **중복 통제** — Section 232 는 상태 변화가 6개입니다. 그대로 더하면 "기록을 많이 쓴
  사건"이 기계적으로 커집니다. 사안 안에서는 최댓값 하나만 씁니다.
- **분류 안은 최댓값** — 냉연·열연·후판 무역구제는 서로 독립 증거가 아니라 **같은 경제
  채널**입니다.
- **분류 사이는 결합** — 관세와 에너지 공급 차질은 다른 채널이므로 독립 증거로
  결합합니다. V2 의 평균 집계는 기록 없는 분류를 분모에 남겨 신호를 상시 희석했습니다.
  이 방식에서는 빈 분류가 `(1−0)=1` 을 곱하므로 **희석하지 않습니다**.

## 7. 고정 전에 한 번 교정한 내역 (전체 공개)

초안 규칙으로 패널을 만들어 본 뒤 **한 번** 교정했습니다.

초안(잔존 하한 0.50/0.55, 분류 안에서도 결합)으로 계산한 결과 PEP 중앙값이 **0.9934**,
125개월 중 110개월이 0.95 이상으로 **1 에 붙어버렸습니다**. V2 가 0 쪽에서 상수였던
것의 정확한 거울상입니다.

원인은 개념적이었습니다. 8년째 유지 중인 관세는 압력이 아니라 baseline 인데 초안은
그것을 계속 만점 가까이 세고 있었습니다. 그래서 지속 상태의 잔존 하한을 낮추고
분류 안 집계를 최댓값으로 바꿨습니다.

교정 후 분포 (학습 구간 125개월):

| | min | p25 | 중앙값 | p75 | max | 표준편차 | 서로 다른 값 |
|---|---|---|---|---|---|---|---|
| PEP | 0.2105 | 0.5200 | 0.7234 | 0.8779 | 1.0000 | 0.2122 | 118 |
| NEP | 0.0534 | 0.2933 | 0.4082 | 0.5085 | 0.8708 | 0.1558 | 125 |

**이 교정에서 본 것과 보지 않은 것:**

- 본 것 — PEP/NEP 자체의 분포뿐. 범위·포화·분산·서로 다른 값 개수.
- 보지 않은 것 — 예측 대상 지수 값, 예측값, 어떤 오차 지표도.

교정은 여기서 끝입니다. 성능을 본 뒤에는 이 표를 다시 건드리지 않았습니다.

## 8. 사건 선정 규칙

- **성능을 보지 않고 골랐습니다.** 예측 대상 지수의 가격 차트도, 예측값도, 어떤 오차
  지표도 보지 않았습니다.
- **기사 원문을 쓰지 않습니다.** 언론사 전문·블로그·임의 웹사이트·위키를 근거로 쓰지
  않으며 기사 본문을 저장하지 않습니다.
- **출처는 공식 기관 문서만.** 출처 주소의 호스트가 `.gov` / `.mil` / `.int` 로 끝나지
  않으면 로더가 거부합니다.
- **월을 채우려고 사건을 만들지 않습니다.** 기록이 없는 분류는 비워 둡니다.

### 알려진 날짜 규칙

**인용한 공식 문서의 발행일**을 씁니다. 서명일과 관보 게재일이 다르면 항상 **늦은
쪽(게재일)** 을 택합니다. 이 선택은 결코 미래 정보를 끌어오지 않습니다.

### "위협"과 "실행"을 구분합니다

"해협을 봉쇄하겠다는 위협"과 "해협이 실제로 봉쇄됨"은 **다른 사건**입니다. 전자는
SIGNALLED 이지 IMPLEMENTED 가 아닙니다. 2025년 관련 사안을 조사한 결과 공식 문서로
확인되는 것은 **핵시설 타격**뿐이었고, 봉쇄를 확정 단계로 기록할 근거를 찾지 못해
**그런 기록은 만들지 않았습니다.**

### 평가창 밖 정보 배제

평가 구간은 2025-12-31 에 끝납니다. 그 이후에 처음 알려진 정보는 로더가 **거부**합니다.
조사 중 실제로 마주쳐 의도적으로 제외한 사건이 있습니다.

## 9. 모델에 들어가는 것 / 화면에만 나오는 것

**모델 변수는 PEP, NEP 두 개뿐입니다.** V2 와 개수가 같습니다 — 그래야 차이를
"변수를 더 넣어서"가 아니라 **"같은 개수의 변수를 다르게 정의해서"** 라고 말할 수
있습니다.

정의상 [0,1] 이므로 **표준화하지 않습니다.**

화면 전용(모델 변수 아님): `NET_PRESSURE = PEP − NEP`,
`CONFLICT_PRESSURE = min(PEP, NEP)`.
