# Demo V10 — 결과와 해석

> 방법론은 실행 **전에** 동결해 커밋했다(`V10A-2026-08-29`, `39ffc00`). 결과를 본 뒤
> 소스·target·X·lag·가중치·창·추론·주지표를 하나도 고치지 않았다. V1~V9 는 전부 보존된다.
>
> **과학적 지위: SAME-WINDOW EXTENDED-DATA / REDESIGNED-EVENT EVALUATION.**
> 스크랩 test 월이 V5/V6/V8/V9 와 정확히 같은 50개다. 늘어난 것은 Event 이력과
> Event 표현이므로 **새 holdout 이 아니다.**

## 1. 한 문단 결론

**Event 이력을 51건에서 11,293건으로, 2015-06 에서 2009-01 로 늘리고, 전달 구조를
7단계 온톨로지로 다시 설계하고, 네 상품에서 같은 조건으로 검증했다. Event 는 어디에서도
작동하지 않았다.** 그런데 같은 실험이 **작동하는 것 하나**를 찾아냈다 — 월 중순에 전월
PPI 가 발표되면 예측 오차가 **26~48% 줄어든다.** 실무 가치는 Event 정보가 아니라
**정보 갱신 주기**에 있었다.

## 3. TRACK A — Event 이력은 실제로 늘었다

| | V9 (V3 registry) | **V10** |
|---|---|---|
| 최초 `known_at` | 2015-06-09 | **2009-01-05** |
| 레코드 | 51 transition / 17 episode | **11,293 / 3,124** |
| 커버 개월 | 약 127 | **204 / 204** (결측 연도 0) |
| 구축 방식 | 사람이 공식 문서를 읽고 선정 | **규칙 기반 기계적 편입** |

Federal Register 공개 API 로 2009-01-01 ~ 2025-12-31 을 **연도별 전수** 취득했다
(30,479 문서 → 편입 11,293). 사이트가 안내한 대로 **API 만** 썼고 HTML 을 긁거나
CAPTCHA 를 우회하지 않았다.

### 왜 방식을 바꿨나

V9 는 소급 확장을 **거부**했다 — "편향 없는 소급 구축이 불가능하면 만들지 않는다".
그 판단은 옳았다. 사람이 고르는 방식은 hindsight 를 배제했다는 것을 **증명할 수 없다.**

V10 은 고르는 행위 자체를 없앴다. 편입은 **제목에 대한 결정적 함수**다 — 동결된 질의군,
동결된 어휘, 동결된 단계·방향·채널 규칙. 같은 규칙을 같은 API 에 적용하면 누구든 같은
패널을 얻는다.

### 구축 중 고친 버그 (전후 공개)

동결 프로토콜은 낱말경계 매칭을 명시했는데 stage/direction 판정만 부분문자열이었다.
그래서 **`determination` 안의 `termination`** 이 걸려 규제를 강화하는 확정 판정이
해제 조치로 뒤집혔다. 규칙이 아니라 구현을 고쳤다.

| | 부분문자열(버그) | **낱말경계(수정본)** |
|---|---|---|
| DOWN | 3,406 | **945** |
| UP | 3,490 | **4,768** |
| TERMINATION | 518 | **215** |

수정 중 만든 두 번째 버그(빈 어휘 목록이 전부 매치)도 잡았다. 둘 다 **성능을 보기 전**이며
어떤 모델도 아직 적합하지 않았다.

| | V9 | **V10** |
|---|---|---|
| Event 기제 | 게이트 상수 (std 0.032, `g>0.5` **0/50**) | **살아 있음** — `ev_net` 50개 origin 에서 **50개 서로 다른 값** (std 3.54) |
| 예측을 움직인 달 | 사실상 0 | **50 / 50** (평균 수정폭 **4.98** 지수 포인트) |

V9 는 "게이트가 열리지 않아서"로 설명할 여지가 있었다. **V10 은 그 변명을 없앴다.**

> 신호는 매달 다르고, 매달 예측을 움직이고, 그 움직임은 **동전 던지기와 구분되지 않는다.**
> leave-one-out 50개 부분표본 **전부**에서 음수다(최소 −1.13%, 최대 −3.02%).

### 4-5. 동결 신호 정의가 퇴화했다 — 고치지 않고 보고한다

성능을 보기 전에 "`ev_new > 0` 인 달을 Event 신호월로 본다"고 정의했다. 그런데 레코드가
11,293건이라 **50개월 전부가 신호월**이 됐다.

| | 값 |
|---|---|
| 신호월 | **50 / 50** |
| precision | **0.20** (= 기저율) |
| recall | 1.00 |
| lift | **1.00** |

**정의를 사후에 바꾸지 않았다.** 밀집 패널에서 이진 "신규 사건 있음" 지표가 무정보가
된다는 것 자체가 결과다. 퇴화를 설명하는 서술 진단은 `post_freeze_descriptive` 로
분리 기록했고 어떤 주장에도 쓰지 않았다(참고로 `ev_net` 상위 20% 기준에서는
precision 0.50 · lift 2.5 였다 — **다음 단계의 단서일 뿐 V10 의 근거가 아니다**).

## 5. TRACK D — 교차 target (1차 matched)

공통 학습 시작 **2014-09**, 같은 50개 예측시점. 첫 시점에서 네 대상의 학습행이
**정확히 86행으로 같다.**

| 대상 | M0 | M1 | M2 | 시장정보 skill | **Event 증분 skill** | p | 유익한 수정 |
|---|---|---|---|---|---|---|---|
| 철·강 스크랩 | 50.54 | 49.45 | 51.04 | +2.16% | **−3.21%** | 0.284 | 0.48 |
| 철광석 | 5.24 | 5.06 | 4.99 | +3.49% | **+1.36%** | 0.403 | 0.48 |

| 원유 | 24.70 | 26.66 | 26.04 | −7.93% | **+2.34%** | 0.072 | 0.46 |

*MAE 는 상품 안에서만 비교한다 — 네 지수는 단위·수준·변동성이 다르다.*

### 5-1. 동결 8조건을 통과한 대상이 **하나도 없다**

가장 좋았던 두 셀을 규칙에 그대로 넣는다.

| 조건 | 원유 matched | 철광석 matched |
|---|---|---|
| C1 최강 비-Event 기준선 개선 | ✓ (M1 26.66 → 26.04) | ✓ (M1 5.06 → 4.99) |
| C2 상대 개선 ≥ 3% | **✗ 2.34%** | **✗ 1.36%** |
| C3 동결 추론 지지 | **✗ p=0.072** | **✗ p=0.403** |
| C4 1~2개 origin 탓 아님 | ✓ LOO **50/50 양** | ✓ LOO **50/50 양** |
| C5 precision 실질 개선 | ✗ | ✗ |
| C6 오경보율 하락 | ✗ | ✗ |
| C7 유익한 수정률 > 0.5 | **✗ 0.46** | **✗ 0.48** |
| C8 기제가 비자명 | ✓ | ✓ |

**판정: `EXPLORATORY_PARTIAL`. 승격하지 않는다.**

C4 는 통과했다는 점을 적어 둔다 — 원유·철광석의 양의 증분은 50개 leave-one-out
부분표본 **전부에서 양**이었다. **일관되게 작지만, 작다.**

### 5-2. 스크랩만 어려운 것이 아니다

> **구리 스크랩이 두 이력 모드 모두에서 가장 크게 실패한다**(−9.60% / −12.20%).
> 그런데 같은 구리에서 **시장정보는 가장 크게 성공한다**(+21.63%).

X 설계의 유효성과 Event 의 무효성은 **별개 축**이다. "우리 X 가 나빠서 Event 가
필요해 보이는 것"이라는 해석은 구리 사례가 배제한다.

## 6. TRACK D — 2차 maximum-history 강건성

| 대상 | Event 증분 matched | Event 증분 maximum |
|---|---|---|
| 철·강 스크랩 | −3.21% | −2.16% |
| 철광석 | +1.36% | **−0.08%** |
| 구리 스크랩 | −9.60% | **−12.20%** |
| 원유 | +2.34% | **−2.22%** |

프롬프트 §32 의 네 시나리오 중 **어디에도 들어맞지 않는다.** 실제로 관측된 것은
다섯 번째 패턴이다.

> **이력을 늘리면 비-Event 기준선이 강해지고, 그때 Event 증분이 사라지거나 음이 된다.**
>
> 원유가 가장 선명하다 — 학습행 86 → 144 로 M1 이 **19% 좋아지자**(26.66 → 21.59)
> Event 의 +2.34% 가 **−2.22%** 로 뒤집혔다.

Event 가 하던 일은 "새 정보를 더하는 것"이 아니라 **약한 기준선의 빈틈을 메우는 것**이었다.
기준선이 스스로 그 빈틈을 메우면 Event 는 남길 것이 없다.

## 7. TRACK E — 완전 주간 rolling nowcast **(V10 최대 성과)**

V9 주간과 다르다. V9 은 시장 baseline 을 W0 에 고정하고 Event 만 예측을 고치게 했다.
**V10 은 매 cutoff 에서 M0/M1/M2 를 전부 다시 적합한다.** 2,000행, 오류 0.

### 7-1. 월이 흐르면 예측이 크게 좋아진다

| 대상 (matched) | 모델 | W0 | W1 | W2 | W3 | W4 | 변화 |
|---|---|---|---|---|---|---|---|
| 철·강 스크랩 | M0 | 50.54 | 50.54 | 31.9 | 26.3 | **26.34** | **−47.9%** |
| 철·강 스크랩 | M1 | 49.45 | 49.45 | 31.1 | 27.5 | 27.86 | −43.7% |
| 철광석 | M1 | 5.06 | 5.06 | 3.6 | 3.4 | **3.32** | **−34.3%** |
| 구리 스크랩 | M1 | 35.10 | 35.10 | 27.7 | 25.5 | **24.82** | **−29.3%** |
| 원유 | M0 | 24.70 | 24.70 | 21.1 | 18.2 | **18.15** | **−26.5%** |

> **W0 와 W1 의 오차가 항상 정확히 같고, W2 에서 급감한다.**
> 전월 PPI 가 대상월 **중순에 발표**되기 때문이다. 억지로 만든 주간 소스가 아니라
> **릴리스 캘린더가 실제로 만드는 정보 도착**이며, 네 상품에서 동일하게 나타난다.

주간 시장 계열은 채택하지 않았다 — EIA 주간은 현재 개정값만 공개돼 PIT 재구성이

## 8. 과학적 결론

**A. 확장된 Event 이력이 표본 한계를 풀었는가 — 아니다.**
2015-06~ → 2009-01~, 7,709 → 11,293 건. MAE 변화 **−0.00% (p=0.998)**.

**B. 새 전달 표현이 스크랩 예측을 개선했는가 — 아니다.**
M1 대비 −2.16%(최대이력) / −3.21%(matched). LOO 50/50 전부 음수.

**C. Event precision 이 개선됐는가 — 측정할 수 없었다.**
동결 신호 정의가 밀집 패널에서 퇴화했다(50/50 신호월, lift 1.00). 정의를 바꾸지 않았다.

**D. 오경보율이 낮아졌는가 — 아니다.** 0.80 (V9 0.70보다 나쁘다).

**E. matched 이력에서 다른 상품이 스크랩보다 나았는가 — 유의하게는 아니다.**
원유 +2.34%(p=0.072), 철광석 +1.36%(p=0.403) 가 양이지만 **동결 임계 3% 미달**.
구리는 −9.60% 로 스크랩보다 나쁘다.

**F. maximum 이력에서 결론이 바뀌는가 — 바뀌지 않는다. 오히려 약해진다.**
철광석 +1.36 → −0.08, 원유 +2.34 → −2.22.

**G. 상품 간 차이의 원인은 — 혼합이되, 이력 깊이가 주범은 아니다.**
이력을 늘리면 Event 는 좋아지지 않고 **나빠진다.** 가장 잘 맞는 설명은
"Event 는 약한 기준선의 빈틈을 메울 뿐"이다.

**H. 주간 rolling nowcast 가 유용한 궤적을 주는가 — 그렇다. 크게.**
네 상품 모두에서 W0→W4 오차가 **26~48%** 줄고, 유익한 수정이 유해한 수정의 두 배다.

**I. M2 가 어떤 주간 단계에서든 M1 을 넘는가 — 스크랩 W2~W4 에서 넘는다.**
다만 같은 시점에서 M0 가 더 낫고 사전등록 비교가 아니므로 탐색적 관찰로만 남긴다.

**J. 가장 강한 긍정적 발견 — 정보 갱신 주기의 가치.**
월 중순 PPI 발표 하나로 예측 오차가 **절반 가까이** 준다. 이것은 모델이 아니라
**운영 설계**의 결과이며, 네 상품에서 재현된다.

**K. 가장 강한 부정적 발견 — Event 는 기제가 살아 있어도 무익하다.**
V9 의 "게이트가 안 열려서"라는 설명 여지를 V10 이 없앴다. 신호는 매달 다르고 매달
예측을 움직이지만, 그 움직임은 동전 던지기와 구분되지 않는다. 그리고 이것은
**스크랩 고유의 문제가 아니다** — 네 상품 어디에서도 통하지 않는다.

**L. 가장 큰 남은 한계 — 여전히 같은 50개월이다.**
스크랩 1차 비교는 V5 이래 같은 창을 재사용한다. 독립적인 새 증거가 아니다.
급변도 10개월뿐이라 급변 구간 수치는 점 추정치다.
