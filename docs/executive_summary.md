### 문제

철스크랩은 전기로 제강의 핵심 원가입니다. 가격은 월 단위로 크게 움직이지만
구매·재고 의사결정은 그보다 먼저 이뤄져야 합니다. "다음 달 가격이 어디로 갈 것인가"에
대해 **재현 가능하고 검증된** 판단 근거가 필요합니다.

### 예측 대상

**BLS WPU1012 — Iron and steel scrap.** 미국 노동통계국이 발표하는 철·강 스크랩
제품군의 **생산자물가지수(PPI)** 입니다. 특정 기업의 구매가격이나 특정 grade 의
$/ton 거래가격이 아니라, 미국 생산자 단계에서 관측되는 가격 움직임을 지수화한
공식 통계입니다.

### 접근 방법

무료 공개 데이터만으로, 각 과거 시점에서 **그때 실제로 공개되어 있던 정보만** 사용해
다음 달을 예측합니다. 결과를 보기 전에 실험 규칙을 문서로 고정(사전등록)하고 그
규칙을 그대로 실행했습니다.

### 데이터 신뢰성

- 설명 변수: BLS · 미국 연준의 **원기관 발표 원문**에서 직접 재구성한 6개 지표
- 상업 데이터 재배포 플랫폼(FRED/ALFRED) **의존도 0**
- 모든 값은 발표일(release date)과 원문 해시로 추적됩니다

### 모델 3단계 — 동일 Train/Test

| 단계 | 내용 |
|---|---|
| **M0** | 과거 PPI 이력 10개 지표 |
| **M1** | M0 + 시장/산업 데이터 12개 |
| **M2** | M1 + 공식 사건 압력(PEP/NEP) 2개 — 탐색적 확장 |

Demo V2에서는 세 단계가 **완전히 같은 예측 시점·학습 행·대상 월·지표**를 사용합니다.
비교 방식도 두 가지를 함께 제시합니다: 알고리즘을 Ridge로 고정한 **통제 비교**와,
각 시점의 학습 데이터 안에서만 모델을 고르는 **Best-CV 벤치마크**.

### 결과 해석

사전등록 실험에서는 시장·산업 데이터를 추가한 M1이 과거 가격만 쓰는 M0를 개선한다는
통계적 증거가 나오지 않았습니다. 결과가 기대와 달랐지만 사전에 고정한 조건을 바꾸지
않았습니다 — 결과를 본 뒤 조건을 조정했다면 그 숫자는 믿을 수 없었을 것입니다.

지금 얻은 것은 "이 조건에서는 개선되지 않는다"는 **재현 가능한 출발점**이며, 다음
실험을 설계할 근거가 됩니다.

### Agent Team 활용 효과

공식 출처 조사 → 과거 발표본 재구성 → 시점별 파서 개발 → 개정/누수 QA → 자동 테스트 →
사전등록 → 실행 → 대시보드까지 End-to-End로 수행했습니다. 특히 **데이터 시점 정합성
검증과 회귀 테스트**를 사람이 손으로 하기 어려운 규모로 자동화했습니다.

### 향후 계획

1. 설명 변수 확대 — 원자재 가격·전방 수요 지표의 공식 취득 경로 확보
2. **환율/달러 지수 등 글로벌 가격경쟁력 변수 추가 검토**
3. 사건 정의와 장기 이력을 더 보강한 뒤 **새로운 사전등록**으로 정식 검증
4. 월간 자동 갱신 파이프라인 연결
