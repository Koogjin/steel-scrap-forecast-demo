### 문제

철스크랩은 전기로 제강의 핵심 원가입니다. 가격은 월 단위로 크게 움직이지만,
구매·재고 의사결정은 그보다 먼저 이뤄져야 합니다. "다음 달 가격이 어디로 갈 것인가"에
대해 **재현 가능하고 검증된** 판단 근거가 필요합니다.

### 접근 방법

무료 공개 데이터만으로, 각 과거 시점에서 **그때 실제로 공개되어 있던 정보만** 사용해
다음 달을 예측하는 파이프라인을 만들었습니다. 결과를 보기 전에 실험 규칙을 문서로
고정(사전등록)하고, 그 규칙을 그대로 한 번 실행했습니다.

### 데이터 신뢰성

- 예측 대상: **공개 철스크랩 가격지수** (US BLS PPI, WPU1012) — 특정 회사 구매가격이 아닙니다
- 설명 변수: BLS · 미국 연준의 **원기관 발표 원문**에서 직접 재구성한 6개 지표
- 상업 데이터 재배포 플랫폼(FRED/ALFRED) **의존도 0**
- 모든 값은 발표일(release date)과 원문 해시로 추적됩니다

### 모델 3단계

| 단계 | 내용 | 지위 |
|---|---|---|
| **N0** | 가장 최근에 발표된 값을 그대로 사용 | 기준선 |
| **M0** | 과거 가격 이력 10개 지표 | 공식 · 사전등록 |
| **M1** | M0 + 시장/산업 데이터 12개 | 공식 · 사전등록 |
| **M2** | M1 + 공식 사건 압력(PEP/NEP) | **탐색적 Demo** |

### 결과

이번 평가창(50개 예측 시점, 2021-11 ~ 2025-12)에서 **시장·산업 데이터를 추가한 M1 이
과거 가격만 쓰는 M0 를 개선한다는 통계적 증거는 나오지 않았습니다.**

이것은 실패가 아니라 **검증된 사실**입니다. 결과가 기대와 달랐지만 사전에 고정한
모델·기간·지표를 바꾸지 않았습니다. 만약 결과를 본 뒤 조건을 조정했다면 그 숫자는
믿을 수 없었을 것입니다. 지금 얻은 것은 "이 조건에서는 개선되지 않는다"는 재현 가능한
출발점이며, 다음 실험을 설계할 근거가 됩니다.

### Claude Code 활용 효과

공식 출처 조사 → 과거 발표본 수집 → 시점별 파서 개발 → 개정/누수 QA → 자동 테스트 →
사전등록 → 실행 → 대시보드까지, 연구자가 원칙과 판단 기준을 정의하고 Claude Code 가
조사·구현·검증·문서화를 가속했습니다. 특히 **데이터 시점 정합성 검증과 회귀 테스트**를
사람이 손으로 하기 어려운 규모로 자동화했습니다.

### 향후 계획

1. 설명 변수 확대 — 현재 미확정(UNRESOLVED) 상태인 원자재·에너지·환율 지표의 공식 취득 경로 확보
2. 사건 압력 변수의 지지 구간 문제 해결 후 **새로운 사전등록**으로 재검증
3. 월간 자동 갱신 파이프라인 연결
