### 문제

철스크랩은 전기로 제강의 핵심 원가입니다. 가격은 월 단위로 크게 움직이지만
구매·재고 의사결정은 그보다 먼저 이뤄져야 합니다. "다음 달 가격이 어디로 갈 것인가"에
대해 **재현 가능하고 검증된** 판단 근거가 필요합니다.

### 예측 대상 — 한 문장으로

**미국에서 철스크랩이 지난달보다 비싸졌는지 싸졌는지를, 다음 달에 대해 미리 맞혀보는
것입니다.**

대상은 **BLS WPU1012 — Iron and steel scrap**, 미국 노동통계국이 발표하는 철·강 스크랩
제품군의 **생산자물가지수(PPI)** 입니다. 가격표가 아니라 **가격의 온도계**입니다.

> 지수 600은 톤당 600달러라는 뜻이 **아닙니다.** 500 → 550 은 약 10% 지수 상승이지
> $50/ton 상승이 아닙니다. 지수 차이는 항상 **변화율**로 읽습니다.

### 접근 방법

무료 공개 데이터만으로, 각 과거 시점에서 **그때 실제로 공개되어 있던 정보만** 사용해
다음 달을 예측합니다. 결과를 보기 전에 실험 규칙을 문서로 고정(사전등록)하고 그
규칙을 그대로 실행했습니다.

### 모델 구조 — 정보를 세 층으로 쌓습니다

| 층 | 의미 |
|---|---|
| **M0** | 가격 자체가 가진 정보 (과거 PPI 이력) |
| **M1\*** | 시장·산업 정보가 **추가로** 설명한 부분 |
| **M2\*** | 공식 Event 정보가 **추가로** 설명한 부분 |

모든 모델이 **완전히 같은 예측 시점·학습 행·대상 월·지표**를 사용합니다.

### 이번 단계의 결과 — 있는 그대로

**1. 시장·산업 정보 모델이 처음으로 과거 가격 모델을 넘었습니다.**

이전까지는 시장 변수를 넣으면 오히려 예측이 나빠졌습니다. 원인을 진단해 보니, 모델이
**하나의 규제 강도**를 전체에 적용하고 있어서 잡음 많은 시장 변수를 억누르려면
**유용한 가격이력 신호까지 함께 눌러야** 했습니다.

이번에는 가격이력·시장·Event 에 **각각 다른 규제 강도**를 적용했습니다. 그 결과
통제 비교에서 시장 모델이 과거 가격 모델보다 **4.2% 정확**해졌습니다.
다만 **아직 통계적으로 확실한 수준은 아닙니다.**

**2. 공식 Event 정보는 이번에도 예측 정확도를 개선하지 못했습니다.**

네 가지 정보 조합(시장 유무 × Event 유무) 어디에서도, 두 분석 방식 모두에서 개선이
없었습니다. 가장 뚜렷한 것은 시장 정보 위에 Event 를 얹었을 때의 악화입니다.

**3. 다만 Event 로 인한 예측 교란은 크게 줄었습니다.**

이전 버전에서는 Event 가 **모든** 예측시점에서 강제로 사용되어 예측을 크게
흔들었습니다. 이번에는 모델이 학습 근거를 보고 **90%의 시점에서 Event 를 쓰지 않기로
스스로 판단**합니다. 그 결과 이전 Event 모델 대비 오차가 24% 줄었습니다 —
**Event 를 유용하게 만든 것이 아니라 해롭지 않게 만든 것**입니다.

### 이번 단계에서 새로 알게 된 가장 중요한 것

**모델 선택 자체가 과적합의 주된 원천이라는 것을 정량적으로 확인했습니다.**

예측 시점마다 후보 모델이 수백~수천 개인데, 내부 검증에 쓸 수 있는 달은 36개뿐입니다.
예측 대상과 **아무 관계가 없는 난수**를 넣어 시험했더니 내부 검증 오차가 중앙값
1.6%(시장) / 5.6%(Event) '개선'되었습니다.

그래서 "확장 정보는 기본 모델보다 12% 이상 나아야 채택한다"는 문턱을 두었습니다.
이 문턱이 Event 잡음을 막았지만, 동시에 **진짜 시장 신호도 일부 막았습니다.**

### 데이터 신뢰성

- 설명 변수: BLS · 미국 연준의 **원기관 발표 원문**에서 직접 재구성한
  **6개 원천지표 → 12개 파생 Feature**
- 상업 데이터 재배포 플랫폼(FRED/ALFRED) **의존도 0**
- 모든 값은 발표일(release date)과 원문 해시로 추적됩니다
- **이번 단계에서도 새로운 외부 데이터 소스를 추가하지 않았습니다**
- **공식 사건 기록을 성능을 본 뒤 고치지 않았습니다**

### Agent Team 활용 효과

**한 모델에게 모든 업무를 한 번에 시킨 것이 아니라, 프로젝트를 역할별로 분해하고
전문 Agent 가 각 업무를 수행하도록 구성했습니다.** 공식 출처 조사 → 과거 발표본
재구성 → 시점별 파서 개발 → 개정/누수 QA → 자동 테스트 → 사전등록 → 실행 → 진단 →
재설계 → 대시보드까지 End-to-End 로 수행했습니다.

특히 이번 단계의 핵심 성과인 **"모델 선택 과적합" 진단**은 독립 QA 관점에서 합성
난수 실험을 설계해 얻은 것입니다.

### 향후 계획

1. **더 긴 Point-in-Time 이력 확보** — 현재 가장 큰 제약은 모델이 아니라 표본 크기입니다
2. 시장 모델의 개선이 통계적으로 확인될 만큼 평가 구간 확대
3. 설명 변수 확대 — 원자재 가격·전방 수요 지표의 **공식** 취득 경로 확보
4. 환율/달러 지수 등 글로벌 가격경쟁력 변수의 라이선스·PIT 요건 검토
5. 월간 자동 갱신 파이프라인 연결
