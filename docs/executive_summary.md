### 문제

철스크랩은 전기로 제강의 핵심 원가입니다. 가격은 월 단위로 크게 움직이지만
구매·재고 의사결정은 그보다 먼저 이뤄져야 합니다. "다음 달 가격이 어디로 갈 것인가"에
대해 **재현 가능하고 검증된** 판단 근거가 필요합니다.

### 예측 대상 — 한 문장으로

**미국에서 철스크랩이 지난달보다 비싸졌는지 싸졌는지를, 다음 달에 대해 미리 맞혀보는
것입니다.**

대상은 **BLS WPU1012 — Iron and steel scrap**, 미국 노동통계국이 발표하는 철·강 스크랩
제품군의 **생산자물가지수(PPI)** 입니다. 가격표가 아니라 **가격의 온도계**입니다.

> 지수 600은 톤당 600달러라는 뜻이 **아닙니다.** 500 → 550 은 약 10% 지수 상승이지
> $50/ton 상승이 아닙니다. 지수 차이는 항상 **변화율**로 읽습니다.

특정 기업의 구매가격도, 특정 grade 의 $/ton 거래가격도 아닙니다.

### 접근 방법

무료 공개 데이터만으로, 각 과거 시점에서 **그때 실제로 공개되어 있던 정보만** 사용해
다음 달을 예측합니다. 결과를 보기 전에 실험 규칙을 문서로 고정(사전등록)하고 그
규칙을 그대로 실행했습니다.

### 데이터 신뢰성

- 설명 변수: BLS · 미국 연준의 **원기관 발표 원문**에서 직접 재구성한
  **6개 원천지표 → 12개 파생 Feature**
- 상업 데이터 재배포 플랫폼(FRED/ALFRED) **의존도 0**
- 모든 값은 발표일(release date)과 원문 해시로 추적됩니다
- **이번 단계에서 새로운 외부 데이터 소스를 추가하지 않았습니다**

### 모델 구조 — 정보를 층으로 쌓습니다

| 층 | 의미 |
|---|---|
| **M0** | 가격 자체가 가진 정보 (과거 PPI 이력) |
| **M1-R** | 시장·산업 정보가 **추가로** 설명한 부분 |
| **M2-R** | 공식 Event 정보가 **추가로** 설명한 부분 |

이 구조의 핵심은 **`M2-R − M1-R` 이 정의상 정확히 Event 보정폭**이라는 것입니다.
이전 설계에서는 변수를 추가하는 순간 규제 강도가 다시 선택되고 전체 계수가 재적합돼
"Event 정보의 효과"를 분리할 수 없었습니다.

모든 단계가 **완전히 같은 예측 시점·학습 행·대상 월·지표**를 사용합니다.

### 결과 해석 — 있는 그대로

**시장 정보를 더한 M1 도, 공식 Event 정보를 더한 M2 계열도, 단계 보정 구조의
M1-R·M2-R 도 M0 를 개선하지 못했습니다. 이 조건에서 가장 정확한 것은 여전히 과거
PPI 이력만 쓰는 M0 입니다.**

결과가 기대와 달랐지만 사전에 고정한 조건을 바꾸지 않았습니다 — 결과를 본 뒤 조건을
조정했다면 그 숫자는 믿을 수 없었을 것입니다.

### 이번 단계에서 실제로 얻은 것

목표는 정확도 개선이 아니라 **"공식 Event 정보의 효과를 다른 효과와 분리해서 재는
것"** 이었습니다.

1. **이전 단계의 표면적 해석이 틀렸음을 밝혔습니다.** 규제 강도를 단계 간에 고정하고
   비교하니, 이전에 관측된 악화의 **약 83% 는 Event 정보 때문이 아니라 규제 재선택과
   계수 재적합** 때문이었습니다. 순수 Event 추가 비용은 통계적으로 구분되지 않는
   수준이었습니다.
2. **규제가 Event 신호를 억누르고 있었음을 정량화했습니다.** 유계 [0,1] 압력 변수는
   같은 예측 기여를 만들기 위해 계수가 약 4.6배 커야 하고, 규제 벌점은 약 21배를
   치릅니다. 추측이 아니라 실행 전에 측정한 값입니다.
3. **억제를 풀자 신호는 크게 움직였지만 방향이 맞지 않았습니다.** 보정폭 중앙값은
   15 지수 Point 로 커졌으나 방향 적중률은 54% — 동전 던지기와 구분되지 않았습니다.
   **움직임의 크기와 정확도는 다른 문제**라는 것이 이번 단계의 결론입니다.
4. **정직함의 비용도 측정했습니다.** 보정 층이 배우는 잔차는 더 짧은 구간으로 학습된
   약한 모델의 잔차라서 실제보다 큽니다. 이 불일치가 V4 정확도 악화의 상당 부분을
   설명합니다.

### Agent Team 활용 효과

**한 모델에게 모든 업무를 한 번에 시킨 것이 아니라, 프로젝트를 역할별로 분해하고
전문 Agent 가 각 업무를 수행하도록 구성했습니다.** 공식 출처 조사 → 과거 발표본
재구성 → 시점별 파서 개발 → 개정/누수 QA → 자동 테스트 → 사전등록 → 실행 → 진단 →
재설계 → 대시보드까지 End-to-End 로 수행했습니다. 특히 **데이터 시점 정합성 검증과
회귀 테스트**를 사람이 손으로 하기 어려운 규모로 자동화했습니다.

### 향후 계획

1. **더 긴 Point-in-Time 이력 확보** — 현재 가장 큰 제약은 모델이 아니라 표본 크기입니다
2. 압력이 높은 구간에서 잔차 구조가 달라지는 현상(부호 반전)의 원인 규명
3. 설명 변수 확대 — 원자재 가격·전방 수요 지표의 **공식** 취득 경로 확보
4. 환율/달러 지수 등 글로벌 가격경쟁력 변수의 라이선스·PIT 요건 검토
5. 방향 정확도를 1차 지표로 두는 별도 사전등록의 타당성 검토
6. 월간 자동 갱신 파이프라인 연결
