# Demo V6 — 결과와 해석 (Event 예측역할)

> 방법론은 실행 **전에** 문서와 설정 파일로 고정(freeze)해 커밋했고, 결과를 본 뒤
> 라벨·임계값·예측기간·후보군을 고치지 않았습니다.
> 사전등록 공식 결과와 V2·V3·V4·V5 는 전부 보존됩니다.

## 0. 왜 V6 를 했나

V1~V5 는 **"Event 정보가 다음 달 지수 수준을 더 잘 맞히는가"** 를 충분히
조사했고 답은 일관되게 **아니오**였습니다.

V6 는 그 결과를 뒤집으려는 것이 아닙니다. **다른 질문**을 새로 사전등록했습니다.

> 공식 Event 정보가 **방향**, **큰 변동**, **전환점** 에 대해서는 —
> 설령 지수 수준을 못 맞히더라도 — 추가 정보를 담고 있을까?

---

## 1. 결론

**네 가지 예측 역할 어디에서도 Event 의 증분 예측가치가 관측되지 않았습니다.**

| 예측 역할 | Event 를 더했을 때 | 판정 |
|---|---|---|
| **지수 수준** (1개월, V5 동결) | MAE 48.83 → 51.04 | **악화** |
| **방향** (1개월) | 정확도 −0.036 (p = 0.430) | **악화** |
| **큰 변동** (1개월) | 감지력 −0.035 (p = 0.372) | **악화** |
| **전환점** (1개월) | 정확도 −0.059 (p = 0.343) | **악화** |

---

## 2. 1차 가설 — 1개월 방향 예측

방향은 **"그 시점에 알고 있던 마지막 실측치보다 오를 것인가 내릴 것인가"** 로
정의했습니다. 발표 지연 때문에 "직전 달 값"은 예측 시점에 알 수 없으므로,
실제로 알고 있던 값을 기준으로 삼았습니다.

| 모델 | 정보 | 방향 정확도 | 비고 |
|---|---|---|---|
| M0-D | 과거 PPI | 0.487 | 동전 던지기 이하 |
| **M1-D** | + 시장 | **0.547** | **가장 정확** |
| ME-D | + Event | 0.484 | |
| M2-D | + 시장 + Event | 0.511 | |

**M1 → M2 : −0.036** (95% 구간 [−0.165, +0.023], p = 0.430)

**Event 를 더하면 방향 정확도가 낮아집니다.** 통계적으로 유의하지는 않지만
개선의 증거가 전혀 없습니다.

**시장 정보는 방향에서도 도움이 됐습니다** (M0 → M1 **+0.060**). V5 에서 시장
정보가 지수 수준 예측을 처음으로 개선한 것과 같은 방향입니다.

---

## 3. 확인용 기간 (2개월 / 3개월)

**예측기간의 우선순위는 실행 전에 고정했습니다: 1개월이 1차, 2·3개월은 확인용.**

| 기간 | 시장만 (M1) | 시장+Event (M2) | Event 만 (ME) |
|---|---|---|---|
| **1개월 (1차)** | **0.547** | 0.511 | 0.484 |
| 2개월 | 0.554 | 0.549 | 0.491 |
| 3개월 | 0.458 | 0.458 | **0.587** |

### 3개월의 ME 결과에 대해 — 정직하게

3개월에서 **Event 만 쓴 모델이 0.587** 로 이번 실행의 유일한 양(+)의 신호입니다
(+0.143, p = 0.062). **그러나 이것을 결론으로 삼지 않습니다.**

- 3개월은 **사전등록된 확인용 기간**입니다. 결과가 좋은 기간을 나중에 골라
  1차라고 부르지 않는다는 규칙을 실행 전에 고정했습니다.
- 같은 모델이 **1개월에서 −0.003, 2개월에서 −0.021** 입니다. 3개월만 뒤집히는
  것은 일관된 신호의 모습이 아닙니다.
- 이번 실행에서 계산한 주요 비교가 **28개**입니다. 다중비교를 보정하지 않은
  p = 0.062 는 단독 근거가 되지 않습니다.

**다음 단계에서 독립적으로 확인할 가설 후보로만 기록합니다.**

## 4. 큰 변동 · 전환점

### 큰 변동 (상위 25% 규모의 움직임)

기준선은 각 시점의 **과거 데이터만으로** 정했습니다.

| 모델 | 감지력 (1개월) |
|---|---|
| **M0-L** | **0.356** |
| M1-L | 0.342 |
| ME-L | 0.309 |
| M2-L | 0.307 |

Event 를 더하면 감지력이 떨어집니다.

### 전환점 (상승↔하락 전환)

| 모델 | 전환 감지 정확도 |
|---|---|
| M0-T | 0.422 |
| M1-T | 0.375 |
| ME-T | 0.394 |
| M2-T | 0.316 |

**모든 모델이 동전 던지기(0.50)보다 낮습니다.** 전환 사례가 50개 중 27개로
**표본은 충분했습니다.** 즉 이것은 표본 부족이 아니라, **이 데이터에서 전환점
자체가 예측되지 않는다**는 뜻입니다.

## 5. 이번 단계의 핵심 발견 — Event 는 학습에서만 유용해 보인다

각 모델이 **학습 내부 검증**에서 낸 정확도와 **실제 예측**에서 낸 정확도의
차이입니다. 양수면 학습에서 더 좋아 보였다는 뜻입니다.

| 모델 (1개월 방향) | 학습에서 더 좋아 보인 정도 |
|---|---|
| 과거 PPI 기반 (M0) | +0.020 |
| **시장 정보 (M1)** | **−0.003** |
| **Event 정보 (ME)** | **+0.096** |
| **시장 + Event (M2)** | **+0.068** |

**시장 정보만 쓴 모델은 격차가 사실상 0** 입니다 — 학습에서 보인 만큼 실제로도
맞혔습니다. 반면 **Event 를 포함한 모델만 격차가 큽니다.**

전환점 예측에서는 시장+Event 모델의 격차가 **+0.237** 까지 벌어집니다.

### 흥미로운 대조

| | V5 (지수 수준) | V6 (방향) |
|---|---|---|
| 모델이 Event 를 **쓰지 않기로** 한 비율 | **90%** | **20%** |
| Event 를 **전부 신뢰**한 비율 | — | **72%** |

V5 의 지수 수준 모델은 Event 를 거의 거부했는데, V6 의 방향 모델은 학습 기준으로
Event 를 **대부분 받아들였고 그 판단이 틀렸습니다.**

---

## 6. 새로 만든 Event 표현은 도움이 됐나

V6 는 개념적으로 새로운 것을 딱 두 개만 추가했습니다.

- **TRANSITION (전이)** — 새로운 발표 / 시행 / 격화 같은 상태 변화 그 자체
- **FRESHNESS (신선도)** — 최근 Event 가 얼마나 새로운 정보인지

| | 결과 |
|---|---|
| 전이가 발생한 달 | 28% |
| 신선도 중앙값 | 0.25 |
| **선택된 Event 표현** | 기존 표현 **69%** · 새 표현(전이+신선도) **31%** |

두 feature 모두 의도대로 동작했지만, **학습 데이터는 이들을 넣지 않는 쪽을 더 자주
선택했고, 넣은 경우에도 예측이 개선되지 않았습니다.**

---

## 7. 가장 큰 남은 한계

**예측 시점 50개, 내부 검증 36개월이라는 규모 자체입니다.**

V5 는 후보 모델 수가 과적합의 통로임을 보였습니다. V6 는 후보를 **63개**로 줄였는데도
Event 모델의 학습-실제 격차가 **+0.07 ~ +0.24** 로 남았습니다.

이 규모에서는 방향 정확도의 오차범위가 ±0.07 수준이라, **실제로 존재하는 작은 신호와
우연을 구분할 검정력이 없습니다.** 1개월 방향의 신뢰구간이 [−0.165, +0.023] 인 것이
그 사실을 그대로 보여줍니다.

**새 변수·새 예측역할·새 모델이 아니라, 더 긴 과거 이력만이 이 한계를 풉니다.**

---

## 8. 경영진 보고용 한 줄

> 공식 Event 정보는 지수 수준뿐 아니라 **방향·큰 변동·전환점 어디에서도** 예측을
> 개선하지 못했습니다. Event 는 과거 데이터에 맞출 때는 유용해 보이지만 실제
> 예측에서는 그 유용성이 재현되지 않습니다. 반면 **시장·산업 정보는 지수 수준과
> 방향 양쪽에서 일관되게 도움이 되는 방향**을 보였습니다.

## 9. 하지 않은 것

- 다음 버전을 시작하지 않았습니다.
- 새 데이터·새 Event 기록을 추가하지 않았습니다.
- 결과를 본 뒤 라벨·임계값·예측기간을 바꾸지 않았습니다.
- 3개월의 양의 결과를 1차 결론으로 승격하지 않았습니다.
- 과거의 부정적 결과를 지우지 않았습니다.
