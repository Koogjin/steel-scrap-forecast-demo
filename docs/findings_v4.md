# Demo V4 — 결과와 해석

> 방법론은 실행 **전에** 문서와 설정 파일로 고정(freeze)해 커밋했고, 실행은
> **정확히 한 번**입니다. 결과를 본 뒤 어떤 설정도 바꾸지 않았습니다.
> 사전등록 공식 결과(N0/M0/M1)와 Demo V2·V3 는 전부 보존됩니다.

**결론을 먼저 씁니다: V4 의 단계 보정 구조는 정확도 면에서 실패했습니다.**
부정적 결과를 숨기지 않습니다. 다만 그 실패가 왜 일어났는지, 그리고 그 과정에서
무엇이 **처음으로 분리되어 측정됐는지**가 이번 단계의 실질적 성과입니다.

---

## 1. 이번 단계가 답하려던 질문

> **공식 Event 정보(PEP/NEP)가, 가격 이력과 시장·산업 정보로 설명되지 않고 남은
> 부분을 실제로 추가로 설명할 수 있는가?**

V3 까지는 이 질문에 답할 수 없었습니다. `M2 − M1` 이 **두 효과가 섞인 값**이었기
때문입니다.

```
M2 − M1  =  Event 정보의 직접 효과  +  규제 강도 재선택 · 전체 계수 재적합 효과
```

V3 의 최대 변화 시점에서 직접 효과는 **+4.03** 인데 재적합 효과가 **−40.11** 이었고
총 변화는 **−36.08** 이었습니다. Event 신호는 예측을 **올리려** 했는데 관측된 총
변화는 크게 내려간 것입니다.

---

## 2. V4 가 바꾼 것 — 층으로 쌓기

정보를 한꺼번에 넣지 않고 층으로 쌓습니다.

| 층 | 하는 일 |
|---|---|
| **M0** | 과거 PPI 이력만으로 예측 (공식 M0 와 동일) |
| **M1-R** | M0 가 설명하지 못한 부분을 **기존** 시장·산업 정보로 보정 |
| **M2-R** | M1-R 이 설명하지 못한 부분을 공식 Event 정보로 보정 |

이 구조에서 **`M2-R − M1-R` 은 정의상 정확히 Event 보정폭**입니다. 자동 테스트가
모든 예측 시점에서 이 항등식을 강제합니다.

**새로운 외부 데이터는 하나도 추가하지 않았습니다.** 기존 6개 원천지표 →
12개 파생 Feature 만 사용했습니다.

---

## 3. 성능 — 있는 그대로

같은 예측 시점 50개, 같은 학습 행, 같은 대상 월입니다.

| 모델 | 의미 | MAE ↓ | 지위 |
|---|---|---|---|
| N0 | 직전 가용치 그대로 | 50.32 | 공식 |
| **M0** | **과거 PPI 기반** | **49.19** | **공식** |
| M1 | 시장·산업 정보 추가 | 50.75 | 공식 |
| M2-V2 | 공식 Event 확장 V2 | 50.72 | 탐색 |
| M2-V3 | Event 표현 고도화 V3 | 51.61 | 탐색 |
| M1-shared | 동일 규제 시장정보 | 50.75 | 진단 |
| M2-shared | 동일 규제 + Event | 50.90 | 진단 |
| M1-R | 시장정보 보정 모델 | 60.99 | 탐색 |
| M2-R | Event 정보 보정 모델 | 67.40 | 탐색 |

**가장 정확한 것은 여전히 과거 PPI 이력만 쓰는 M0 입니다.**

---

## 4. 가장 중요한 발견 — V3 악화의 83%는 Event 정보가 아니었다

규제 강도를 **M1 이 고른 값으로 고정**한 채 Event 변수만 추가하면:

| | M1 대비 MAE 변화 |
|---|---|
| M2-V3 (V3 · 규제 재선택 허용) | **+0.865** |
| M2-shared (규제 고정) | **+0.149** (통계적으로 구분되지 않음) |

**V3 에서 관측된 악화의 약 83% 는 Event 정보 때문이 아니라, 변수를 추가하면서
규제 강도가 다시 선택되고 전체 계수가 재적합된 결과였습니다.**

이것이 이번 단계에서 가장 방어 가능한 결과입니다. "Event 정보가 예측을 망친다"는
V3 의 표면적 해석은 **틀렸습니다.**

---

## 5. Event 정보는 이제 크게 움직인다 — 그러나 방향이 맞지 않는다

| | V3 (한꺼번에 넣기) | **V4 (층으로 쌓기)** |
|---|---|---|
| median 보정폭 | 0.20 | **15.17** |
| max 보정폭 | 36.08 | **87.33** |
| \|보정\| < 1 인 시점 | 86% | **2%** |
| \|보정\| > 5 인 시점 | — | **80%** |

**규제가 Event 신호를 억누르고 있었던 것은 사실입니다.** 실행 전에 측정한 바로는,
유계 [0,1] 인 압력 변수가 같은 예측 기여를 만들려면 계수가 약 **4.6배** 커야 하고
규제 벌점은 약 **21배** 를 치릅니다.

그런데 억제를 풀자:

| 항목 | 값 |
|---|---|
| 보정 방향이 실제로 맞은 비율 | **54%** |
| 보정 후 오차가 줄어든 / 커진 시점 | **25 / 25** |
| MAE 변화 (M1-R → M2-R) | **+6.41** |

방향 적중률 54% 는 동전 던지기와 구분되지 않는데 보정 크기는 15 지수 Point 입니다.
**큰 보정 × 무작위 방향 = 분산 주입입니다.**

즉 "규제가 유용한 정보를 죽이고 있었다"가 아니라 **"규제가 부정확한 신호를 눌러
손실을 줄이고 있었다"** 에 가깝습니다.

---

## 6. 왜 단계 보정 구조가 무너졌나 — 정직함의 비용

보정 층이 학습하는 '설명되지 않은 부분'은 **그 시점에 실제로 관측 가능했어야**
합니다(prequential 규칙). 그래서 학습 구간 안에서 다시 앞→뒤로 적합·예측을 반복해
잔차를 만들었습니다.

여기에 대가가 있었습니다.

| | 오차 크기 |
|---|---|
| 보정 층이 배우는 잔차 (짧은 구간으로 학습된 모델) | **59.64** |
| 최종 M0 가 실제로 내는 오차 | **49.19** |

보정 층은 **더 약한 모델**의 잔차 크기를 배운 뒤 그것을 **더 강한** 모델 위에
얹습니다. 그 결과:

| 항목 | 값 |
|---|---|
| median 시장 보정폭 | **24.65** 지수 Point |
| median M0 실제 오차 | 29.54 |
| 보정 크기 / 오차 크기 | **0.83** |
| 시장 보정 방향이 맞은 비율 | **42%** (동전 던지기보다 나쁨) |

고치려는 오차의 83% 크기로 보정하는데 방향은 절반도 못 맞힙니다.
**M0 → M1-R 의 MAE 악화(+11.80)는 이 구조의 직접적 귀결입니다.**

---

## 7. Event 가 강한 시기에 더 유용했나 — 기대와 반대

동결된 임계값(결과를 보기 **전에** 고정) 기준:

| 구분 | 시점 수 | M1-R MAE | M2-R MAE | 변화 |
|---|---|---|---|---|
| Event 활발한 달 | 42 | 62.23 | 70.58 | **+8.34 악화** |
| 조용한 달 | 8 | 54.47 | 50.73 | **−3.74 개선** |

**가설과 반대 방향입니다.** 다만 조용한 달은 **8개뿐**이므로 어떤 유의성도 주장하지
않습니다. 서술적 관찰로만 기록합니다.

학습 데이터 전용 진단에서는 압력이 높은 구간의 잔차가 **2.3배 크고 부호가
뒤집혔습니다**. 선형 보정이 다루기 어려운 구조이며, **다음 단계 후보로만
기록합니다** — 결과를 보고 모델을 추가하지 않았습니다.

---

## 8. 무엇이 선택됐나

| 층 | 선택 분포 (50개 예측 시점) |
|---|---|
| 시장 보정 모델 | Ridge 22 · ElasticNet 17 · **PLS 11** |
| Event 표현 | **E1 (수준 + 변화) 22** · E2 (수준 + 1개월 전) 20 · E0 (수준) 8 |
| Event 보정 모델 | **Ridge 27** · Huber 14 · OLS 9 |

- 상관이 높은 시장 변수를 소수 요인으로 압축하는 **PLS 가 22% 의 시점에서
  선택**됐습니다 — 12개 변수가 실제로 겹친다는 학습 데이터상의 신호입니다.
- Event 층은 예측변수가 2~4개뿐인데도 학습 CV 는 **절반 이상 규제를 골랐습니다**.
  규제 없는 OLS 는 9/50 에 그쳤습니다.

## 9. 정직한 최종 해석

1. **Event 정보가 이제 의미 있는 예측 영향력을 갖는가?** — **크기 면에서는 그렇습니다.**
   정확도 면에서는 아닙니다.
2. **그 영향이 정확도를 개선하는가?** — **아닙니다.** MAE +6.41, 방향 적중 54%,
   개선/악화 25:25.
3. **Event 정보는 조건부로 유용해 보이는가?** — 기대와 반대로 조용한 구간에서만
   개선됐고 표본이 8개입니다. **주장할 수 없습니다.**
4. **단계 보정이 한꺼번에 넣기보다 나은 구조인가?** — **정확도로는 아닙니다.**
   **효과를 분리해 재는 목적으로는 명백히 낫습니다.** 두 목적을 분리해야 합니다.
5. **M1 은 왜 여전히 약한가?** — 시장 변수의 상당 부분이 이미 가격 이력에 들어
   있고(최대 R² 0.89), 변수끼리 겹치며(최대 상관 0.97), 72행 표본에서 22개 변수가
   전체 규제를 끌어올리기 때문입니다.
6. **가장 큰 남은 한계** — **표본 크기입니다.** 학습행 72~118, 예측 시점 50개.
   이 규모에서는 층을 하나 더 쌓을 때 생기는 추정 분산이 어떤 신호 이득보다 큽니다.
   새 변수나 새 모델이 아니라 **더 긴 Point-in-Time 이력**이 근본 제약입니다.

---

## 10. 하지 않은 것

- 다음 버전을 시작하지 않았습니다.
- 새로운 외부 데이터를 추가하지 않았습니다.
- 결과를 본 뒤 Event 채점 규칙을 고치지 않았습니다.
- 최종 결과를 본 뒤 어떤 튜닝도 하지 않았습니다.
- 부정적 결과를 숨기지 않았습니다.
