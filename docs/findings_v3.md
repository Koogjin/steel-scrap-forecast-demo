## 3. 가장 중요한 발견 — "겹쳐 보인다"의 진짜 이유

`M2 − M1` 이라는 숫자는 **두 경로가 섞인 값**입니다.

```
합계    =  M2 예측  −  M1 예측
직접    =  M2 예측  −  M2 예측(사건 변수를 0 으로)     ← 계수 × 압력
간접    =  M2 예측(사건=0)  −  M1 예측                 ← 나머지 계수 재적합
```

같은 학습행에 변수가 2개 늘면 모델은 **나머지 모든 계수를 다시 적합**합니다. 교차검증이
다른 정규화 강도를 고르면 변화는 훨씬 커집니다.

| | M2-V2 | M2-V3 |
|---|---|---|
| 직접 효과 중앙값 / 최대 | 1.34 / 25.58 | 0.96 / 9.22 |
| 간접(재적합) 중앙값 / 최대 | 1.02 / 24.88 | 0.90 / 40.11 |
| **합계 중앙값 / 최대** | **0.32 / 1.08** | **0.20 / 36.08** |

**V2 에서 두 선이 겹쳐 보인 진짜 이유:** 아무 일도 없어서가 아니라, **크기가 비슷한 두
효과가 서로 상쇄됐기 때문**입니다.

**V3 의 최대 변화(2023-09, −36.08)도 사건 때문이 아니었습니다:**

```
합계 −36.08  =  직접 +4.03  +  간접 −40.11      (정규화 강도 100 → 10 으로 재선택)
```

사건 압력이 예측을 민 힘은 **+4.03 지수 포인트**였습니다. 나머지는 변수가 2개 늘면서
교차검증이 다른 정규화 강도를 고르고, 그 결과 다른 모든 계수가 다시 적합된 데서
나왔습니다. 이 한 시점이 M2-V3 와 M1 의 MAE 격차(0.86) 중 **0.72** 를 혼자 만듭니다.

## 4. 그래서 무엇을 알게 되었나

1. **사건을 압력 신호로 표현하는 것 자체는 가능합니다.** 공식 문서만으로, 성능을 보지
   않고, 재현 가능한 규칙으로 유계 신호를 만들 수 있었고 실제로 움직입니다.
2. **그 신호는 모델에 도달합니다.** 계수는 0 이 아니고, 사건 변수를 껐다 켜서 효과를
   직접 측정할 수 있습니다.
3. **그런데 지금 설계에서는 "M2 vs M1" 비교 자체가 교란되어 있습니다.** 변수를 추가하면
   정규화 강도 재선택과 계수 재적합이 함께 일어나므로, 관측된 차이를 사건 정보의
   효과라고 부를 수 없습니다.
4. **이 조건에서 사건 압력은 정확도를 개선하지 않았습니다.** 유의한 악화도 아닙니다.
   **"증거 없음"이 결론입니다.**

## 5. 다음 실험 설계 (이번에 실행하지 않았습니다)

지금 결과를 근거로 V3 의 정의를 고치지 않습니다. 대신 다음 사전등록에서 다룹니다.

- **정규화 강도를 단계 간에 고정**해 재적합 교란을 제거합니다.
- **사건 압력을 잔차에만 얹는** 2단계 설계로 직접 효과만 분리합니다.
- 예측 시점 50개는 사건 효과를 검정하기에 작습니다. 평가창을 늘리거나, 사건이 실제로
  발생한 시점에 가중치를 두는 조건부 평가를 사전등록합니다.
- 방향 정확도는 M1/M2-V2 가 0.600 으로 M0(0.540)보다 높습니다. MAE 가 아니라 **방향**을
  1차 지표로 두는 별도 사전등록이 타당한지 검토합니다.
