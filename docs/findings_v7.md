# Demo V7 — 결과와 해석 (Event 위험 · 조건부 가치)

> 방법론은 실행 **전에** 문서와 설정 파일로 고정(freeze)해 커밋했고
> (`V7A-2026-08-27`), 결과를 본 뒤 구간 수준·tail 임계값·상호작용 짝·모형 계열을
> 고치지 않았습니다.
> 사전등록 공식 결과와 V2·V3·V4·V5·V6 는 전부 보존됩니다.

## 0. 왜 V7 을 했나

V1~V6 는 **정확도** 질문을 충분히 조사했습니다 — 지수 수준, 방향, 큰 변동,
전환점. 답은 일관되게 **아니오**였습니다.

V7 은 그 결과를 뒤집으려는 것이 아닙니다. 경영 현장이 실제로 쓰는 것은 점 하나가
아니라 **"얼마나 틀릴 수 있는가"** 이기 때문에, 다음 네 가지를 새로
사전등록했습니다.

| Track | 질문 | 지위 |
|---|---|---|
| **A** | Event 정보가 **예측 불확실성 구간**을 더 잘 맞히는가 | **PRIMARY** |
| B | Event 정보가 **급등·급락 위험**을 감지하는가 | 보조 |
| C | Event 효과가 **시장 상황에 따라** 달라지는가 (사전선언 3개) | 보조 |
| D | **발표 직전 창에 새로 들어온** Event 정보가 더 유용한가 | 보조 |

점 예측 모델(M1\*)은 V5 에서 동결된 채 **그대로** 두었습니다. V7 은 그 주변의
불확실성만 다룹니다.

## 1. 결론

**1차 가설은 지지되지 않았고, 사전에 정한 중단 규칙이 발동했습니다.**

| Track | 비교 | 지표 | 결과 | p | 판정 |
|---|---|---|---|---|---|
| **A (PRIMARY)** | U0 → U1 | 80% Interval Score | 258.3 → 229.2 | 0.318 | **지지 안 됨** |
| B 상단 | T0 → T1 | Brier | 0.159 → 0.218 | 0.324 | 악화 · **표본 부족** |
| B 하단 | T0 → T1 | Brier | 0.031 → 0.037 | 0.003 | 악화 · **표본 부족** |
| C | M1 → M2-INT | MAE | 47.14 → 46.27 | 0.354 | 개선 방향 · 유의하지 않음 |
| D 지속형 | M1 → M2-PERSIST | MAE | 47.14 → 48.43 | 0.769 | 악화 |
| D 발표창 | M1 → M2-RW | MAE | 47.14 → 48.96 | **0.00005** | **유의하게 악화** |

강한 보조 근거 **0건**. 유의하게 나온 두 결과는 **모두 악화 방향**입니다.

## 2. Track A (PRIMARY) — 예측 불확실성

평가 시점 **37개** (prequential 오차가 12개 이상 쌓인 origin 부터).

| | Interval Score ↓ | 실제 커버리지 | 평균 폭 |
|---|---|---|---|
| **U0** Event 없음 | 258.27 | **1.000** | 258.27 |
| **U1** Event 조건부 | 229.22 | **1.000** | 229.22 |

차이 −29.05 · p = 0.318 · 95% 구간 [−19.56, +62.98] → **지지되지 않습니다.**

### 이 실행에서 더 중요한 발견

**목표는 80% 인데 두 구간 모두 실제 커버리지가 100% 였습니다.** 37개 시점 중
실제값이 구간을 벗어난 경우가 **한 번도 없었습니다.**

구간 폭은 **과거 예측오차 분포**에서 나옵니다. 그 과거에는 2021~2022년의 격변기가
들어 있고, 평가 구간(2023~2025)은 훨씬 잔잔했습니다. 즉 **오차 분포 자체가 시간에
따라 변했습니다(non-stationary).**

그래서 이 비교는 "잘 보정된 두 구간 중 어느 쪽이 나은가"가 아니라 **"둘 다 지나치게
넓은 것 중 어느 쪽이 덜 넓은가"** 입니다. 이 점을 과장하지 않고 그대로 적습니다.

같은 이유가 Track B 의 표본 부족도 설명합니다.

---

## 3. Track B — 급등·급락 위험

임계값은 **학습 구간의 prequential 잔차 분위수**(상위 20% / 하위 20%)로 정했고,
결과를 본 뒤 조정하지 않았습니다.

| | 양성 사례 | 사전 규칙 최소치 | 판정 |
|---|---|---|---|
| 상단(급등) | **4건** | 10건 | **UNDERPOWERED** |
| 하단(급락) | **1건** | 10건 | **UNDERPOWERED** |

두 tail 모두 Event 를 넣은 T1 의 Brier 가 더 나빴습니다. 하단의 p = 0.003 은
**악화 방향**이고 양성이 1건뿐이라 해석 가치가 없습니다.

**표본이 부족했다는 사실 자체를 결과로 보고합니다.** 임계값을 낮춰 양성을 늘리는
것은 결과를 본 뒤의 조정이므로 하지 않았습니다.

## 4. Track C — 시장 상황별 Event 효과

**실행 전에 정확히 3개**만 선언했습니다. 결과를 본 뒤 짝을 바꾸지 않았습니다.

| 상호작용 | 충격 | 시장 상태 |
|---|---|---|
| INT-A | 철강·무역 정책 충격 | 1차금속 가동률 (CAPUTLG331S) |
| INT-B | 지정학·공급 충격 | 전력비용 모멘텀 (WPU0542) |
| INT-C | 수요·거시 충격 | 산업생산 모멘텀 (INDPRO) |

통제 트랙 50개 시점: MAE **47.14 → 46.27** (−0.87, p = 0.354).

**이번 단계에서 유일하게 개선 방향으로 나온 결과입니다.** 다만

- 통계적으로 유의하지 않고,
- **보조 가설**이며 1차 가설을 대체하지 않고,
- 세 개를 함께 시험했는데 **다중비교 보정이 없고**,
- **통제 트랙**의 숫자여서 V5 의 운영 결과와 직접 비교되지 않습니다.

그래서 이것을 "Event 가 드디어 작동했다"고 쓰지 않습니다. 이 정도 크기와 유의성은
**표본 50개에서 우연히 나올 수 있는 범위 안**입니다 (V5 의 난수 실험 참조).

## 5. Track D — 발표창 신규 Event

같은 Event 를 두 방식으로 넣었습니다.

| | MAE | 차이 | p |
|---|---|---|---|
| M1 (시장 정보만) | 47.14 | — | — |
| M2-PERSIST (지속형 표현) | 48.43 | +1.29 | 0.769 |
| **M2-RW (발표창 신규분만)** | **48.96** | **+1.82** | **0.00005** |

예측 직전 창에서 **새로 들어온** Event 만 쓴 모델이 **유의하게 더 나빴습니다.**

이것은 실행 전에 기록해 둔 예상과 일치합니다 — 월 단위 예측에서 "발표창 신규분"은
V6 의 transition impulse 와 상당 부분 겹치며, 겹치는 만큼 새 정보가 아니라 잡음이
됩니다.

## 6. 중단 규칙 (STOP RULE)

V7 을 시작하기 **전에** 다음을 적어 두었습니다.

> 1차 가설이 지지되지 않고 보조 가설에서도 일관된 강한 근거가 나오지 않으면
> **Event 모델 개발을 중단한다.** V8 을 시작하지 않고, 새 Event feature 도 새
> 모형 계열도 새 사건 기록도 추가하지 않는다.

조건이 충족되었으므로 규칙대로 멈춥니다.

다음 단계는 새 변수가 아니라 **더 긴 Point-in-Time 이력 확보**입니다.
계획서: `docs/next_phase_plan.md` (계획만 — 이번 단계에서 실행하지 않았습니다).

## 7. V1~V7 을 관통하는 하나의 답

| 단계 | 같은 제약이 나타난 모습 |
|---|---|
| V5 | 예측 대상과 **아무 관계 없는 난수**조차 내부검증을 중앙값 1.6%(시장)·5.6%(Event) "개선" |
| V6 | Event 를 포함한 모델만 **학습–실제 정확도 격차 +0.07 ~ +0.24** |
| V7 | 80% 구간이 **100% 과대커버** · 급등 사례 **4건** |

셋은 서로 다른 모형 문제가 아니라 **하나의 표본 문제**입니다 — 예측 시점 50개,
내부검증 36개월, 학습행 72~118행.

**새 Event feature 도 새 모형도 이것을 풀지 못합니다.**

### 실행 중 고친 것 (숨기지 않고 기록합니다)

첫 실행에서 Track C 의 상호작용 값이 예측 시점 행에서 전부 결측(NaN)으로

깨진 경로만 건드렸다는 직접적인 증거입니다.
